# 消息格式及示例

功能与分数口径见 [功能规格](../docs/SPEC-model-discovery.md)，实现见 [设计](../docs/design-model-discovery.md)。下例为合成排版样本。

````
智商雷达：09-08 16:00（北京时间）
共 1 个模型 / 1 个档位
工程数据：09-08 15:55
视觉数据：09-08 15:50

```
模型 / 档位       综合    工程    视觉   耗时
example-model   110.00  100.00  130.00  4.0分
```
````

- 标题、模型数量与两个数据源时间在代码块外。
- 代码块不附加语言标签；列宽按完整名称与中文显示宽度动态计算。
- 所有有效模型档位均列出，未知分项使用破折号。新增模型沿用相同排版。
- 验证覆盖全量记录、完整名称、中英文对齐、缺失分项、零分与源时间。
- 接口异常由任务明确报告，禁止将缺失数据包装成正常推送。
