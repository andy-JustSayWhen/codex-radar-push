# 全量模型智商同步

## 用户可见行为

- 定时推送和即时智商查询使用网站实时软件工程及视觉空间数据，遍历所有返回的模型与推理档位。新增模型、版本及档位不需要修改配置或代码。
- 默认输出模型、综合智能、软件工程、视觉空间、平均耗时。综合智能与网站一致：仅在两个分项均有有效题量和分数时，按有效题量加权；耗时采用相同权重且要求两侧均有耗时。
- 任一分项已取得成绩的模型均保留；缺失项目显示 `—`。不以缺失耗时为由隐藏模型，不把缺失分数当零分。
- 标题显示生成时间，同时单独显示两个数据源的更新时间。模型名称保留网站的完整识别名称与推理档位，按名称稳定排序；不使用模型白名单。
- 维持现有定时任务的频率、目标及身份。每次定时运行读取最新列表；即时查询与变化提醒复用相同处理。
- 数据请求失败、缓存被网站标记过期、响应格式异常或整份数据无有效成绩时明确失败，不回退到缺少模型的旧入口。变化提醒的临时网络失败仍保持既有静默行为，不推进比较状态。
- 同一模型、档位的重复记录保留较新成绩；存在冲突且无法确定先后时明确失败。仅顺序或整体抓取时间变化不触发智商变化提醒，新增模型及成绩变化会触发。
- 变化提醒沿用运行环境的 30 分钟冷却时间，首次运行输出完整结果；冷却期间保留尚未提醒的变化。固定时刻的全量表格任务仍由既有任务定义控制。

## 验收

- 真实网站返回的全部有效模型档位均出现在推送和查询中，含 GPT-6 的全部已测档位。
- 测试使用虚构的新模型及未知档位证明无需手动补名单，并覆盖零分、缺失耗时、重复记录、异常数据、综合加权及新增模型提醒。
- 部署前备份应用文件；部署后核对文件摘要、运行环境内测试、真实查询和既有任务的投递回读。
