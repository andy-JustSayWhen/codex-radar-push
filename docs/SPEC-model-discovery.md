# GPT 模型智商同步

## 用户可见行为

- 定时推送与即时智商查询只展示 GPT 模型，使用网站实时软件工程智商分数及平均耗时。遍历接口中所有以 `gpt-` 开头的模型，新版本、新档位自动纳入。
- 输出保持三列：模型、分数、耗时。标题为“降智雷达：时:分”，表格使用无语言标签的代码块。
- 名称采用网站模型简称，例如 Sol、Terra、Luna、5.5；新模型名称根据接口自动生成。同名但不同版本的模型补上版本号以区分。
- 模型族沿用网站顺序，档位从强到弱排列，未知档位仍保留。分数保留源精度并省略多余零，耗时四舍五入为整数分钟；缺失耗时显示破折号且保留模型。
- 消息内容仅包含标题与三列表格。普通智商查询与定时推送使用同一张表。
- 保持既有任务时间、会话及身份。数据失败或过期明确报错，不回退旧入口；整份数据没有有效 GPT 成绩时失败。
- 变化判断仅包含 GPT 名称、档位、分数及耗时。顺序、抓取时间、题量及其他厂商模型变化不触发提醒；新增 GPT 模型会触发。
- 变化提醒保持 30 分钟冷却及首次推送行为，冷却期间保留未提醒变化。

## 验收

- 合成样本验证三列格式、简称、排序、仅 GPT、未来版本与未知档位、零分及缺失耗时。
- 实时抓取的所有有效 GPT 档位均出现在推送和查询中，包含 GPT-6。
- 部署前备份，部署后检查文件摘要、运行环境测试和原任务投递结果。
